# Churn-Prediction-Web
A Machine Learning-powered web application that predicts whether a customer is likely to churn based on customer information and service usage.

## 📌 Project Overview

This project uses a Random Forest Classifier to predict customer churn. The web application is built using Streamlit, allowing users to input customer details and receive instant predictions.

## ✨ Features

- Customer churn prediction
- Interactive Streamlit web interface
- Real-time prediction
- Machine Learning model integration
- Data preprocessing and feature scaling
- Prediction history

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Pickle

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/7865Rida/Churn-Prediction-Web-App.git
```

Navigate to the project folder:

```bash
cd Churn-Prediction-Web-App
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run apps.py
```

The application will open automatically in your default browser.
